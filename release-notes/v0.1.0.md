# Eidolon-Echo v0.1.0

## Summary

First public baseline release for Eidolon-Echo on macOS (Apple Silicon).

## Included

- Desktop app bundle (`Eidolon-Echo.app`)
- DMG installer (`Eidolon-Echo.dmg`)
- Local backend sidecar bundled in app
- Settings center with API / mode / local data actions
- Role mode history view from avatar popup menu
