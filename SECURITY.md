# Security Policy

## Scope

Eidolon-Echo is currently designed for local, single-user use. By default, chat data and provider configuration are stored on the user's local machine.

## Sensitive Data

- Do not post real `api_key` values in issues, discussions, screenshots, logs, or pull requests.
- The current implementation stores `api_key` in plaintext in the local SQLite database.
- Before sharing logs or database files, remove all secrets and private conversation content first.

## Reporting

If you believe you found a security issue, do not disclose exploit details publicly first.

Please contact the maintainer privately through GitHub account contact channels for `HughLFree`. If you cannot reach the maintainer privately, open a minimal public issue without secrets or reproduction details and request a private contact path.
